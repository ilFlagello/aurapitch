# AuraPitch (beta privata)

Le partite di calcio lette in 10 secondi: probabilità dalle quote, forma reale, classifiche, schedina.

- `app/`: la web app installabile, pubblicata automaticamente su GitHub Pages (`.github/workflows/pubblica.yml`).
- `raccoglitore.py`: raccolta quotidiana di partite, quote e quota media (`.github/workflows/raccolta.yml`).
- Le chiavi delle fonti dati stanno solo nei "secrets" del repository, mai nei file.

Dati storici: Football-Data.co.uk, ClubElo. Stemmi generici, non ufficiali.
